# Art and sound credits

All art and sound in this project is **original**, made for Igloo, and released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain). No third-party assets are used.

- `art/`: pixel-art sprites generated by `tools/make_sprites.py`.
- `sfx/`: sound effects synthesized from scratch by `tools/make_sounds.py`.

To tweak them, edit those scripts and run them again with Python 3 (needs `pillow` and `numpy`):

```
python3 tools/make_sprites.py
python3 tools/make_sounds.py
```

When you move to final art, replace the files in `art/` and `sfx/` with the same names, or update the paths in the scripts in `scripts/`.
